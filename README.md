# chugaku-juken-prompts

中学受験の学習を支援する無料の生成AIプロンプト集です。

算数・国語・理科・社会の問題解説、演習問題の作成、家庭学習の効率化を目指します。

**作成・検証したプロンプトは、このGitHubリポジトリに順次保存・公開していきます。**

## 1. まずはChatGPTに課金して使う

中学受験の学習には、まずChatGPTの有料プランを利用することをおすすめします。

無料プランでも利用できますが、写真を使った問題解説を日常的に行う場合は、有料プランのほうが利用制限の面で便利です。

## 2. 写真を撮って問題を解説してもらう

1. 中学受験の問題をスマートフォンで撮影する。
2. ChatGPTに写真をアップロードする。
3. 小学生にも分かるように解説してもらう。
4. 分からない部分を追加で質問する。
5. 類題を作成して理解を確認する。

### 基本プロンプト

```text
あなたは中学受験専門の家庭教師です。

写真の問題を読み取り、
小学4〜6年生にも分かるように
丁寧に解説してください。

条件：
1. 答えだけでなく考え方を説明する。
2. 途中式を省略しない。
3. 原則として中学数学を使わない。
4. 必要に応じて図や表を使う。
5. 間違えやすいポイントを説明する。
6. 最後に答えを検算する。
7. 写真の不明瞭な箇所は推測しない。
```

生成AIの解説には誤りが含まれる場合があるため、重要な問題は必ず確認してください。

## 3. プロンプトを作るプロンプトを用意する

毎回ゼロからプロンプトを考える必要はありません。

プロンプトを自動作成するための共通プロンプトを用意しておくと便利です。

作成するプロンプトには、目的、対象学年、入力内容、解説方法、出力形式、注意点を含めます。

**作成したプロンプトは、そのままテキストファイル（.txt）として保存できる形式で出力します。**

## 4. GPTs・Gemsを活用する

よく使うプロンプトは、ChatGPTのGPTsやGeminiのGemsに登録しておきます。

毎回長い指示を入力する手間を省き、写真をアップロードするだけで問題を解説してもらえる環境を目指します。

GPTs・Gemsの設定用プロンプトもテキストファイルで保存・公開します。

## 5. プロンプトのファイル管理ルール

プロンプトは原則としてテキストファイル（.txt）で管理します。

ファイル名・フォルダ名は英語で統一し、プロンプト本文は日本語で記述します。

### 命名規則

`YYYYMMDD_content_V1.txt`

| 項目 | ルール |
|---|---|
| 日付 | 作成日・改訂日を8桁で記載 |
| 内容 | 短い英語で記載 |
| バージョン | V1、V2、V3で管理 |
| 拡張子 | .txt |

### ファイル名の例

| ファイル名 | 内容 |
|---|---|
| `20261112_math_V1.txt` | 算数の解説 |
| `20261112_geometry_V1.txt` | 図形問題 |
| `20261112_photo_V1.txt` | 写真の問題解説 |
| `20261112_exercise_V1.txt` | 類題作成 |
| `20261112_prompt_builder_V1.txt` | プロンプト自動作成 |
| `20261112_gpt_setup_V1.txt` | GPTs設定 |
| `20261112_gem_setup_V1.txt` | Gems設定 |

README.mdはGitHub上の案内ページとしてMarkdown形式で管理します。

## 6. プロンプト作成時の共通ルール

生成AIで新しいプロンプトを作成する際は、次の指示を追加します。

```text
作成したプロンプトは、
そのままテキストファイル（.txt）に
保存できる形式で出力してください。

ファイル名は必ず
YYYYMMDD_content_V1.txt
の形式にしてください。

ファイル名は短い英語で統一し、
プロンプト本文は日本語で記述してください。

タイトル、目的、使い方、
プロンプト本文、注意点を含めてください。

説明文とプロンプト本文を区別し、
コピーしてすぐ利用できるようにしてください。

テキストファイルを作成できる環境では、
実際に.txtファイルを生成してください。
```

## 7. GitHubでの公開・運用

作成したプロンプトは、このリポジトリに順次追加していきます。

- プロンプトは無料で公開する。
- テキストファイルとして保存できるようにする。
- ファイル名は英語、本文は日本語で統一する。
- 改良したプロンプトはバージョン管理する。
- GPTs・Gemsの設定も共有する。
- 実際の問題で検証し、必要に応じて改善する。。
- 塾や市販教材との併用を歓迎する。

## 目指すもの

生成AIとオープンソースを活用し、誰もが低コストで中学受験に挑戦できる学習環境をつくります。
